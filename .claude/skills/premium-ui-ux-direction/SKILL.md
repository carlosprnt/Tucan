# Premium UI/UX Direction Skill

## Purpose

Use this skill whenever a screen, flow, component, product moment, empty state, or visual direction feels incomplete, generic, unclear, weak, or not premium enough.

This skill raises the design quality bar using best-in-class consumer app principles inspired by products like Revolut, Airbnb, Spotify, Apple, Wise, Linear, Arc, and premium iOS apps.

Do not copy these brands. Use them only as quality references.

## Product Context

The app is GrillMe.

Core loop:

Submit idea → receive AI feedback → improve idea → publish → get community reviews → earn reputation/rewards

Target feeling:

- Premium consumer mobile app
- Sharp but warm
- Minimal but not empty
- Confident
- Editorial
- Fast
- Tactile
- Slightly playful
- Honest
- Useful
- Not childish
- Not corporate
- Not crypto-bro
- Not generic AI SaaS

## When To Use

Use this skill when:

- A screen feels visually weak
- A component feels generic
- Claude is missing UI details
- A Figma frame is incomplete
- A state is missing
- A flow needs better UX
- A screen needs stronger hierarchy
- A product moment needs delight
- Copy feels flat
- Empty/error/loading states feel basic
- A design needs to feel more premium
- A screen needs React Native implementation direction

## Workflow

### 1. Diagnose

Review the screen or flow and identify:

- What is the user trying to do?
- What emotion should this screen create?
- What is unclear?
- What feels generic?
- What feels too busy?
- What feels unfinished?
- What is missing?
- What can be removed?
- What should be emphasized?

### 2. Define the premium direction

Propose:

- Visual hierarchy
- Layout structure
- Spacing rhythm
- Typography direction
- Card structure
- CTA hierarchy
- Icon usage
- Color/token usage
- Motion/interactions
- Empty/error/loading/success states
- Native mobile behavior

### 3. Improve the product moment

For each important screen, define the product moment:

Examples:

- Welcome screen: create trust and curiosity
- Submit Idea screen: make it feel effortless and focused
- AI Feedback loading: create anticipation
- AI Feedback result: make the roast feel sharp, useful, and structured
- Publish confirmation: create momentum
- Community feed: make discovery feel alive
- Profile: make progress and identity feel rewarding
- Rewards: make value feel earned, not scammy

### 4. Produce implementation-ready output

Return:

1. Design diagnosis
2. Recommended screen structure
3. Component list
4. Copy suggestions
5. Interaction notes
6. State requirements
7. React Native implementation notes
8. What not to build
9. QA/design acceptance criteria

## Design Quality Checklist

Check:

- Is the screen instantly understandable?
- Is there one clear primary action?
- Is the visual hierarchy obvious?
- Does the screen breathe?
- Is the typography confident?
- Are cards/components intentional?
- Is the copy short and useful?
- Are states designed, not just handled?
- Does the flow feel mobile-native?
- Does it avoid generic AI-startup aesthetics?
- Does it avoid crypto/trading aesthetics?
- Does it avoid corporate dashboard aesthetics?
- Does it feel ownable for GrillMe?

## Output Format

Use this format:

### Design Diagnosis

Brief and direct.

### Premium Direction

Describe the ideal experience.

### Screen Structure

List the recommended sections in order.

### Components Needed

List reusable components and variants.

### Copy

Provide improved titles, body copy, CTAs, errors and empty states where relevant.

### Interaction & Motion

Describe subtle transitions, loading behavior, feedback, gestures or haptics.

### React Native Notes

Include implementation guidance using existing tokens/components.

### Acceptance Criteria

List what must be true for this to be considered done.

## Rules

- Do not copy any brand directly.
- Do not add unnecessary complexity.
- Do not propose features that distract from the core loop.
- Do not use decoration to hide weak UX.
- Do not suggest crypto-heavy patterns unless specifically required.
- Prefer simplicity, clarity and confidence.
- Be direct when something feels amateur.
